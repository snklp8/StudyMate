Data Structures: Binary Search

Overall Summary

Binary search is an efficient divide-and-conquer algorithm for finding an item from a sorted collection by repeatedly halving the search space.

Important Concepts

  • Array must be sorted in advance.
  • Logarithmic time complexity O(log n).
  • Mid-point formula: low + (high - low)/2

Formulas

Time Complexity: O(log n)
Space: O(1) Iterative
